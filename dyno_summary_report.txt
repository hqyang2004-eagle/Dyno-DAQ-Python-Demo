Dyno Data Summary Report
========================

Project Software Scope
----------------------
This software processes dynamometer data after force and RPM data are collected.
It does not replace measurement hardware, DAQ hardware, absorber control, or safety systems.

Equations Used
--------------
Torque = Force * Torque Arm Length
Horsepower = Torque * RPM / 5252
Torque uncertainty = sqrt((r*uF)^2 + (F*ur)^2)
Horsepower relative uncertainty = sqrt((uT/T)^2 + (uRPM/RPM)^2)
